Grain model setup

One-time SHA-256 check of the packaged Community Forensics weights

Grain runs a public MIT-licensed Community Forensics ViT entirely inside Chrome (WebGPU, then WASM). Image bytes are never uploaded.

If you built from this repository with npm run build, the weights are already packaged. This page verifies their SHA-256 and warms the inference engine. After that the extension works offline.
